# Вимоги бізнес-логіки (ТОВ "ДОЛОТА")
Форма для відвідувачів виставки: Прізвище та ім'я, Телефон (обов'язково, із перевіркою), Email (перевірка), Назва фірми (необов'язково).
Після надсилання: дані зберігаються у базі; якщо номеру ще не було — запускається розіграш подарунка.
Щоб отримати подарунок — верифікація номера через SMS-код. Далі — внутрішня сторінка з кнопкою "Подзвонити нам" і переходом у Telegram-бот.
За згодою — зібрати approximate локацію користувача.
